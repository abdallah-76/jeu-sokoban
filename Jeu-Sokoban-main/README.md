🎮 Jeu Sokoban

Un jeu de réflexion classique inspiré du célèbre Sokoban, où le joueur doit pousser des caisses vers des positions cibles dans une grille.

📌 Description

Ce projet implémente une version du jeu Sokoban avec une interface simple et une logique basée sur une grille.
Le but est de résoudre chaque niveau en plaçant toutes les caisses sur les cases cibles, tout en évitant de se bloquer.

🚀 Fonctionnalités
🧱 Déplacement du joueur sur une grille
📦 Poussée de caisses (une seule à la fois)
🎯 Objectif : placer les caisses sur les cibles
🔁 Gestion des niveaux
🎮 Gameplay simple et intuitif
⚙️ Chargement de niveaux (fichiers texte ou intégrés)
🎮 Règles du jeu
Le joueur peut se déplacer dans 4 directions
Il peut pousser une caisse, mais jamais la tirer
Impossible de traverser les murs ou les caisses
Le niveau est réussi lorsque toutes les caisses sont placées correctement
